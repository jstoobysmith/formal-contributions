# Formal Contributions logo

Generated by [`scripts/draw-logo.py`](../scripts/draw-logo.py). Edit the script and re-run it rather than editing these files by hand:

```sh
python3 scripts/draw-logo.py
```

The wordmark is STIX Two Text (the site's serif) at weight 550, converted to outlines. The SVGs need no web font.

## Files

| File | Use |
| --- | --- |
| `logo.svg` | Main lockup (mark + two-line wordmark) on light backgrounds |
| `logo-inverse.svg` | Same, for navy or dark backgrounds |
| `mark.svg` | The symbol on its own, for light backgrounds |
| `mark-inverse.svg` | The symbol on its own, for dark backgrounds |
| `favicon.svg` | Browser tab icon. Strokes are heavier for small sizes, and it switches to cream in dark mode |
| `favicon.ico` | Fallback favicon (16, 32 and 48 px) |
| `icon.svg` | App icon: the mark on a cream rounded square |
| `png/icon-180.png` | `apple-touch-icon` |
| `png/icon-192.png`, `png/icon-512.png` | Web app manifest icons |
| `png/favicon-{16,32,48}.png`, `png/mark-512.png` | Raster copies for places that can't take SVG |

The SVGs have no fixed `width`/`height`, so size them with CSS. Set the height and the width follows.

## Colours

| Name | Hex |
| --- | --- |
| Navy | `#16223C` |
| Gold | `#A78439` |
| Cream | `#F7F6F2` |

## Wiring into the site

Copy the files into `public/` (for example `public/logo/`), then in `index.html`:

```html
<link rel="icon" href="/logo/favicon.ico" sizes="32x32" />
<link rel="icon" href="/logo/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/logo/png/icon-180.png" />
```
